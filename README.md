
# Random Quotes python app :))
made a python quote app which can fetch quotes and ideas and also questions which are real awesome and are different from all other quote libraries out there :anchor: 



## Requirements :smiley::
1. Install the required dependencies with:
``` bash
    pip install -r requirements.txt
```

## Environment Variable
Create a `.env` file in the root directory and add your Gemini API credentials like this:
    GEMINI_API_KEY="your_api_key_here"
anddddd, you're all set! <br> Now just run the py file and have funn!!
