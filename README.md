
# Random Quotes python app :))

made a python quote app which can fetch quotes and ideas and also questions which are real awesome and are different from all other quote libraries out there :anchor: 


## Environment Variable

To run this project, you will need to add a `"GEMINI_API_KEY"` variable(obv with a api key) in your `.env` file, which you can take from [google ai studio](https://aistudio.google.com/)
